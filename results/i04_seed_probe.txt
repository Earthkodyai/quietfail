==============================================================================
🔴 ผล — setseed **ไม่ได้** ทำให้ build ซ้ำได้
==============================================================================

  เงื่อนไข              query ที่เปลี่ยนคำตอบ (จาก 200)
  A  setseed(0.42) ทุก build      101  (50.5%)
  B  ไม่ setseed เลย              117  (58.5%)

**ถ้า PRNG ของ session เป็นกลไก A ต้องได้ 0** — ได้ 101 จึงตัดออกได้

------------------------------------------------------------------------------
⚠️ ห้ามอ่านว่า "setseed ช่วยลดจาก 117 เหลือ 101"
------------------------------------------------------------------------------

**ค่าฐานเองก็แกว่งข้ามรอบ** — I04 เดิมวัด HNSW ef=40 ได้ **132/200** (2026-07-27)
รอบนี้ค่าฐานได้ **117/200** ทั้งที่เงื่อนไขเดียวกันทุกประการ

  ค่าฐานที่วัดได้จนถึงตอนนี้   117 · 132     (ช่วง 15)
  A ได้                       101           (ต่ำกว่าค่าฐานต่ำสุด 16)

ส่วนต่าง A-B = 16 **อยู่ในระดับเดียวกับที่ค่าฐานแกว่งเอง** และมีเงื่อนไขละ 1 รอบ
จึงบอกไม่ได้ว่าเป็นผลจริงหรือ noise · **ต้องเก็บหลายรอบต่อเงื่อนไขถึงจะตอบได้**

ที่พูดได้อย่างเดียวคือ: **setseed ไม่ได้ทำให้ผลนิ่ง**

------------------------------------------------------------------------------
สิ่งที่ตัดออกได้เพิ่ม — ตอนนี้เป็น 3 สาเหตุ
------------------------------------------------------------------------------

  1. ฝั่ง query        วัดซ้ำบน index ตัวเดิม -> ตรงกันทุก query        (กลุ่มควบคุม ก)
  2. parallel build   ปิดแล้วยังแกว่ง 127/200                          (กลุ่มควบคุม ค)
  3. **PRNG ของ session**  setseed ค่าเดิม -> ยังแกว่ง 101/200         (รอบนี้)

**ข้อ 3 มีน้ำหนักเพราะปิด parallel build ไว้ด้วย** จึงไม่ใช่กรณีที่ worker
มี PRNG แยกแล้ว setseed ไปไม่ถึง — ทุกอย่างอยู่ใน session เดียวที่ setseed แล้ว

------------------------------------------------------------------------------
เหลืออะไรให้คนทำต่อ
------------------------------------------------------------------------------

การสุ่มที่ทำให้กราฟต่างกัน **ไม่ได้มาจาก PRNG ที่ `setseed()` ควบคุม**
ผู้ที่จะทำต่อควรดูที่:

  - pgvector อาจใช้ตัวสุ่มของตัวเอง แยกจาก PRNG ของ session
  - ลำดับการอ่านหน้า (page) ระหว่าง build ซึ่งขึ้นกับสภาพ buffer cache
  - โครงสร้างภายในของ graph ที่ขึ้นกับลำดับการแทรก

**ต้องอ่านซอร์สของ pgvector ถึงจะตอบได้** ซึ่งอยู่นอกขอบเขตของโครงงานนี้
แต่ตอนนี้คำถามแคบลงมากแล้ว และมีหลักฐานว่าอะไร*ไม่ใช่*ครบ 3 ข้อ
