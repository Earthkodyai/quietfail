⭐ V07 เกิดซ้ำเป๊ะ — หายไป 10 แถวพอดี เท่ากับ corpus สังเคราะห์
==============================================================================

  zero <=> query  ->  NaN     (ไม่ใช่ error)
  NULL <=> query  ->  NULL

  เส้นทางที่ 3 ทำหายไป 10 แถวพอดี = NULL 5 + zero 5 ทั้งสองชุดข้อมูล

**กลุ่มควบคุมคือหัวใจ** — เส้นทางที่ 2 มี index อยู่แต่บังคับไม่ให้ใช้ แล้วได้ครบ 510
พิสูจน์ว่า **เส้นทางที่ใช้ index ต่างหากที่ทำหาย ไม่ใช่ข้อมูลหาย**

------------------------------------------------------------------------------
🔴 การวัดรอบแรกใช้ไม่ได้ — และเป็นกับดักของโปรเจคเองสองข้อพร้อมกัน
------------------------------------------------------------------------------

รอบแรกรายงานว่า "ไม่มีแถวหาย" ซึ่งผิด เพราะ

1. **ตาราง 510 แถวเล็กมาก planner เลือก Seq Scan เอง** ไม่เคยใช้ vector index เลย
   ต้องบังคับด้วย enable_seqscan = off (ของเดิมทำไว้แล้ว ผมลอกมาไม่ครบ)

2. ตอนตรวจ plan เห็น "Node Type": "Index Scan" แล้วเกือบเชื่อ
   **แต่นั่นคือ pkey ของ qf_real_q ใน subquery ที่ดึง query vector**
   ตรงกับ **E25 / กฎเหล็กข้อ 6** เป๊ะ — ห้ามค้นคำ ให้ตรวจจากชื่อ index

แก้แล้วโดยเพิ่ม assertion ที่ **หยุดทันทีถ้าเส้นทางที่ 3 ไม่ได้ใช้ vector index จริง**
(กฎเหล็กข้อ 10 — ตรวจไม่ได้ ไม่ใช่ผ่าน)
