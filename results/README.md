# results/

ผลการทดลองดิบ **ห้ามแก้ด้วยมือ** — ทุกไฟล์ต้องมาจากการรันสคริปต์เท่านั้น

## กฎ

- ทุกไฟล์ต้องมีหัวข้อ environment (version + วันที่) อยู่ข้างใน
  ถ้าไม่มี = ใช้อ้างอิงไม่ได้ ให้รันใหม่
- ไฟล์ในโฟลเดอร์นี้ถูก gitignore โดยค่าเริ่มต้น เพราะรันบ่อยแล้วจะรก
- ผลที่จะ**อ้างอิงในรายงาน** ต้อง force add เก็บเป็นหลักฐาน:

```powershell
git add -f results/ชื่อไฟล์.txt
```

## ไฟล์ของ audit — เขียนทับทุกครั้งที่รัน (ไม่ใช่ผลการทดลอง)

| ไฟล์ | สร้างโดย | ใช้ตอนไหน |
|---|---|---|
| `audit_latest.txt` | `python scripts/audit.py` | **ตอนเริ่ม session** — อ่านแทนการไล่ตรวจเอง |
| `audit_reproduce.txt` | `python scripts/audit.py --reproduce` | เมื่อสงสัยว่าผลยังเกิดซ้ำได้ไหม (**33.8 นาที** วัดจริง) |

สองไฟล์นี้ **ไม่เข้ากฎ "ห้ามแก้ด้วยมือ" แบบเดียวกับผลการทดลอง** เพราะถูกเขียนทับทุกครั้ง
แต่ยังต้อง `git add -f` เพื่อให้ session ถัดไปอ่านได้โดยไม่ต้องรันเอง
